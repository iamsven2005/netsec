STEP-BY-STEP BUILD PROCESS
================================================================================

1. Prepare Build Environment
   $ pip install pyinstaller scapy
   $ sudo apt install upx  # Optional
   $ cd scapy/final

2. Generate Build Artifacts
   $ python3 build_executable.py

   This creates: build_toolkit/
   ├── main_executable.py          (wrapper)
   ├── netsec_toolkit.spec         (PyInstaller config)
   ├── [copied source files]       (main.py, etc.)
   └── intercepted/                (data dir)

3. Compile to Binary
   $ cd build_toolkit
   $ pyinstaller netsec_toolkit.spec

   This creates: dist/netsec-toolkit (~130 MB)

4. Verify Binary
   $ file dist/netsec-toolkit
   $ ls -lh dist/netsec-toolkit
   $ sudo dist/netsec-toolkit --help

5. Deploy
   $ scp dist/netsec-toolkit user@target:/tmp/
   $ ssh user@target 'sudo /tmp/netsec-toolkit --demo'
